Activate for API design, endpoint planning, contract definition.

## REST: Resource naming, HTTP methods, TS interfaces, status codes, error format `{error:{code,message,details}}`, cursor pagination, versioning, rate limits.

## GraphQL: Types, Queries, Mutations, Subscriptions, Connection pattern, DataLoader.

## WebSocket: Connection lifecycle (auth, heartbeat, reconnect), JSON with type discriminator, channels, backpressure.

Output TypeScript interfaces with example requests/responses.
