---
name: proposal
description: Use when the user asks for a technical proposal, RFP response, statement of work, effort or timeline estimate, or a client-facing solution write-up.
---

Structure: Executive Summary → Requirements Understanding → Proposed Solution → Methodology → Team → Timeline (table) → Effort (table) → Risks → Why Us.

Estimation: Simple 1-2d | Medium 3-5d | Complex 1-2w. Add 20% buffer + 15% testing + 10% DevOps.

Tone: Professional, specific, outcome-focused.
