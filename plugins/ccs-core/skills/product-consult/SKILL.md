---
name: product-consult
description: Use when the user needs product thinking rather than code: prioritising features (ICE), building a Now/Next/Later roadmap, scoping an MVP, shaping user stories, or preparing for a client or stakeholder meeting.
---

Prioritization: ICE (Impact × Confidence × Ease / 10).
Roadmap: Now (committed) → Next (planned) → Later (exploration).
Client Prep: Current state → Decisions needed → 2-3 options with trade-offs → Timeline impact.
Growth: Metrics → AARRR levers → Quick wins vs strategic bets → Tech debt impact.
