description: Break work into features with complexity, hours and dependencies.
---

Provide an effort estimate for: $ARGUMENTS

Break down into features. For each feature:
1. Description (one line)
2. Complexity: Simple (1-2d) | Medium (3-5d) | Complex (1-2w)
3. Hours estimate
4. Dependencies

Then add:
- 20% buffer for unknowns
- 15% for testing
- 10% for DevOps/deployment setup

Output as a table with totals.
